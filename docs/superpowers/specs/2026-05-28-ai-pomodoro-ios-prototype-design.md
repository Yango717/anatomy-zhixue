# AI 番茄钟 iOS 原型 · 设计规格书

> 日期：2026-05-28
> 状态：已批准

## 概述

一款 AI 增强的番茄钟 iOS 原型，4 个核心屏幕，可点击交互。区别于普通番茄钟的核心差异：AI 智能任务识别、专注模式分析、个性化陪伴式提醒。

## 视觉系统

### 设计方向
Kenya Hara 式东方极简——温暖、安静、克制。米白底色 + 赤土橙单 accent，衬线数字 + 系统无衬线 UI 文字。

### 配色
| 角色 | 色值 | 用途 |
|------|------|------|
| Page BG | `#FBF7F4` | 全局背景 |
| Card BG | `#FFFFFF` | 卡片容器 |
| Accent | `#C04A1A` | 主操作、选中态、进度、高亮 |
| Ink | `#2C2416` | 主文字 |
| Secondary | `#8B7355` | 辅助文字、标签 |
| Warm Gray | `#F2E8DC` | 分隔、未激活态、进度背景 |

### 字体
| 角色 | 字体 | 大小 |
|------|------|------|
| Display（计时数字）| Georgia, serif | 36px |
| Heading | -apple-system, sans-serif | 18px |
| Body | -apple-system, sans-serif | 13-16px |
| Caption | -apple-system, sans-serif | 10-12px |

### 组件语言
- 圆角：卡片 14px，按钮 50%（圆形）/ 22px（胶囊），Tab Bar 16px
- 边框：1-1.5px solid `#F2E8DC` 或 `#E8D5C4`
- 阴影：不使用投影，用边框区分层次
- 间距：12px / 16px / 20px 三级

## 架构

### 导航
底部 Tab Bar，4 个标签：计时 / 洞察 / 统计 / 设置。计时屏为默认首页。Tab 切换无动画过渡，直接替换内容区。

### 屏幕 1：计时主屏
- **顶部**：状态栏 + Dynamic Island（用 ios_frame.jsx）
- **任务区**：AI 推荐时长标签 + 当前任务名称
- **计时区**：conic-gradient 环形进度 + 大号 serif 倒计时数字 + 当前番茄序号
- **操作区**：暂停（小圆）· 开始/继续（大圆 accent）· 跳过（胶囊边框）
- **AI 触点**：计时区下方白色卡片——个性化鼓励语（如「上轮你坚持了 25 分钟，再来一轮？」）
- **底部**：Tab Bar + Home Indicator

### 屏幕 2：AI 洞察屏
- **顶部**：标题「今日洞察」+ 日期
- **摘要卡片**：今日专注时长 / 完成番茄数 / 完成率 三列数字
- **AI 发现卡片**：文字洞察（如高峰时段分析），1-2 条
- **专注时段分布图**：8 个时段的柱状图（8-22 点），accent 色标高峰
- **AI 建议卡片**：连续专注天数等正面反馈
- **底部**：Tab Bar + Home Indicator

### 屏幕 3：统计屏
- **顶部**：标题「专注统计」+ 时间范围切换（本周/本月/全部）
- **大数字区**：总专注时长 + 总番茄数
- **柱状图**：7 天每日专注时长（当前天 accent 色）
- **连续打卡卡片**：当前连续天数 + 个人最佳
- **底部**：Tab Bar + Home Indicator

### 屏幕 4：设置屏
- **顶部**：标题「设置」
- **番茄时长选择**：25 分钟 / 45 分钟 / 自定义（分段选择器）
- **休息设置**：短休息时长 + 长休息时长（行内显示当前值）
- **AI 助手开关**：智能时长推荐 / 专注分析报告 / 个性化鼓励提醒（各带 toggle switch）
- **底部**：Tab Bar + Home Indicator

## 交互规格

### Flow Demo 模式
单台 iPhone，内置状态管理器：
- Tab Bar 点击切换屏幕
- 计时屏：开始/暂停按钮切换倒计时状态，跳过按钮重置
- 设置屏：时长选择、toggle 开关可点击
- 所有可交互元素有 cursor: pointer + hover 反馈

### 技术方案
- 单文件 HTML，内嵌 React + Babel（pinned 版本）
- 使用 `ios_frame.jsx` 标准 iPhone 15 Pro 外壳
- 单文件 inline 架构，所有组件 + 数据 + 样式写在一个 `<script type="text/babel">` 中
- 浏览器 `file://` 直接打开即可使用

## AI 能力（本原型中为模拟数据）

1. **智能任务识别**：计时屏顶部显示 AI 推荐时长（模拟）
2. **专注模式分析**：洞察屏的文字洞察 + 时段分布图（模拟数据）
3. **陪伴式提醒**：计时屏底部的个性化鼓励卡片（模拟）

## 设计约束

- 不做真实 AI 后端调用，全部使用模拟数据
- 计时器用 setInterval 实现前端倒计时
- 不引入外部依赖（除 React + Babel CDN pinned 版本）
- iOS 外壳严格使用 `assets/ios_frame.jsx`，不手写 Dynamic Island / Status Bar
